# Approved knowledge base

This directory is reserved for **approved, versioned official labour-policy/legal source material**.

Do not paste arbitrary web content here.

Every source added for a production deployment should record:
- issuing authority
- title
- publication/effective date
- canonical source location
- retrieval date
- version/hash
- review/approval owner

The AI layer must treat these files as reference material only. It must not infer that a missing source means a requirement does not exist.

The public repository intentionally contains no unverified legal corpus.
