# Instructions for approved reference material

Only approved, versioned legal/policy source material belongs in `data/knowledge/`.
Every file must start with the front-matter block above and must:

- be copied verbatim from the canonical source (or a licenced digest),
- record issuing authority, version and review owner,
- avoid mixing commentary with source text.

The AI layer treats these files as **reference context only**. A missing source
here never means a requirement does not exist.
